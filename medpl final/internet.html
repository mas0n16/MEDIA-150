Playground, factory & surveillance

Key Terms

HTTP — HyperText Transfer Protocol

  • The open protocol for serving web pages — the way computers agree to communicate to deliver websites.
  • Created by Tim Berners-Lee at CERN.
  • Anyone can use it free of charge — you don't need to pay a licensing fee to put up a web page.

CSS — Cascading Style Sheets

  • Controls the visual style of a website — colors, fonts, layout, spacing.
  • Demonstrated by CSS Zen Garden, which shows the same text styled in many different ways with CSS.

JavaScript

  • A prominent coding language for the web that has many libraries to enhance and extend programming possibilities.
  • A library is a "JavaScript file that you include in your page, which then lets you use the functions, objects, methods, and properties it contains" (Jon Duckett).
  • Examples: Three.js (3D and WebGL), A-Frame (VR), Juxtapose, Filter.js.

URL — Uniform Resource Locator

  • The address of a web page — how you specify the location of a resource on the internet.
  • Created by Tim Berners-Lee at CERN.

ARPANET — Advanced Research Projects Agency Network

  • Project started in 1968 — the first nationwide interconnected computer network.
  • Developed because researchers at various universities and labs working on DARPA projects needed to share their work.
  • Fall 1969: Stanford and UCLA had networked computers.
  • By 1970: UCSB, University of Utah, MIT, Harvard, Carnegie Mellon.
  • By 1981: grew to 200 connections.
  • First word ever sent over ARPANET: "lo" — the system crashed while trying to type "login."
  • Roots: President Eisenhower formed DARPA on Jan. 7, 1958 in response to Sputnik (Oct. 4, 1957).

Bonus terms

  • TCP/IP — Transmission Control Protocol / Internet Protocol. The open protocols that govern the flow of the internet's raw data.
  • Protocol — "a way that multiple computers agree to communicate with one another" (Steven Johnson).
  • HTML — Hypertext Markup Language. The standard for marking up web content (HTML5 was published October 28, 2014, adding <video>, <audio>, and <canvas> tags). The W3C (World Wide Web Consortium) sets web standards.

Joseph C.R. Licklider

  • Wrote "Man-Computer Symbiosis" (1960).
  • Director of DARPA's behavioral science office.
  • Conceived of interconnected computers — he saw the importance of a standardized connection for computers.
  • Searched for top talent to work on what he called an "Intergalactic Computer Network" — a network that would allow access to data from anywhere in the world via connected machines, providing efficient shared access to expensive computers.
  • His vision directly inspired the team that built ARPANET.
  • Bob Taylor (one of the programmers Licklider attracted) was famously frustrated by having to switch between three computers in three locations that couldn't talk to each other — this inefficiency motivated the networking effort.
In short

Licklider is the visionary who imagined the internet before it existed — articulating both the concept of a global computer network and the necessity of standardized communication between machines.

Dennis Ritchie

  • Co-creator of Unix (along with Ken Thompson) at Bell Labs, 1969–71.
  • Created the C programming language.

Why this matters for the Internet

  1. Unix was rewritten in C in 1972, which made it easier to code than assembly language and — crucially — hardware independent. You didn't need to rewrite the OS for every new type of computer.
  2. Because of an antitrust case against AT&T, Bell Labs couldn't enter the computer business, so they gave Unix away for free to anyone who requested it.
  3. As a result, universities, government agencies, and companies got free OS software for their mainframes throughout the late 1970s — exactly when programming was taking off at universities, before the PC era. A whole generation of programmers learned on Unix systems.
  4. All Apple computers, iPhones, iPads, and Android OS use a Unix-like system under the hood today.
In short

Ritchie built the technical foundation that made the internet's software ecosystem possible. Unix + C became the standard environment for networked computing, and most of the servers that run today's internet still run on Unix-like systems (Linux is Unix-like). Without Ritchie's work, the open, hardware-independent, sharable software culture that enabled the internet's growth wouldn't have existed.

Centralized vs. Decentralized vs. Distributed

This is essentially the design question that the early internet's architects had to answer.

The Problem

AT&T connected the country with phone lines and switching centers in major cities by 1914. During the Cold War, the telephone switching centers would be high-value targets for Soviet missiles because they were close to major cities — if one was destroyed, the network would fail.

The Three Network Types

Centralized Network

  • A single central hub with all nodes connecting through it.
  • Vulnerability: if the central hub fails, the entire network collapses.

Decentralized Network

  • Multiple hubs, each connected to a cluster of nodes (think AT&T's phone system — regional switching centers).
  • Vulnerability: if a hub fails, that entire region of the network goes down.

Distributed Network

  • Every node is connected to multiple other nodes — no single hub.
  • Benefit: provides redundancy for information delivery in case one node goes down — information can route around damage.
  • Proposed by Paul Baran at the Rand Company (hired by the Air Force). It took Baran 5 years to convince his peers this was the right approach.
  • Donald Davies, a British physicist working independently, also concluded the distributed network was correct. Davies also came up with packet switching — breaking data up into smaller "electronic packets" that could be dispersed across the network.
In short

The distributed model won because it was the only architecture that could survive partial destruction (originally a Cold War concern) and because packet switching made it efficient. This is the architecture the internet is built on.

Tim Berners-Lee

Working at CERN, Berners-Lee created the foundation of the World Wide Web (which sits on top of the internet — different things). His key contributions:

  • Created HTML (HyperText Markup Language) so different types of computers and operating systems (DOS, UNIX, Apple) could all access the same information on the Internet.
  • Created HTTP (HyperText Transfer Protocol) — the protocol for transferring web pages.
  • Created the URL (Uniform Resource Locator) — the system for addressing web pages.
  • CERN distributed the WWW software for free over the Internet — a foundational act for the open web.

His motivation

Information is constantly being lost. The solution was hypertext — "human-readable information linked together in an unconstrained way." Tim Berners-Lee

For Berners-Lee, hypertext was proposed as a solution to improve the computer's ability to support human memory.

The hypertext concept built on Vannevar Bush's earlier idea (1940s): rather than organizing knowledge in rigid hierarchies, researchers should create subjective, associative trails across documents — "the process of tying two items together is the important thing."

Web 1.0 vs. Web 2.0

Web 1.0

  • Built on "open protocols" — ways of exchanging information that anyone can use, owned by no one.
  • Protocols defined and maintained by academic researchers and international standards bodies.
  • Examples of Web 1.0 open protocols still in use today:
    • Email → POP, SMTP, IMAP
    • Websites → HTTP
    • Internet itself → TCP/IP
  • Key characteristic: anyone can use these protocols free of charge. You don't pay a licensing fee to use HTTP for a webpage; you don't sell part of your identity to send an SMTP email.
  • Mostly read-only — users consumed content created by site owners.

Web 2.0

"Sites that leverage user-generated content to create a platform for communication and sharing media" — like Facebook, TikTok, Instagram, and YouTube.

Key characteristics

  • User-generated content drives the platforms.
  • Centralized platforms facilitate and regulate interactions between users.
  • Read/write — users both consume and create.
The shift

From open protocols owned by no one → centralized platforms owned by corporations.

No private company owned the protocols that defined email or GPS or the open web. But one single corporation owns the data that define social identity for two billion people today — and one single person, Mark Zuckerberg, holds the majority of the voting power in that corporation. Steven Johnson, Beyond the Bitcoin Bubble, NYT

Challenges of Web 2.0

  • Service providers may be unable to move data to other platforms without losing reputation and customer base.
  • Service users have limited control over how their data is used.
  • Centralized platforms can filter user content, limit access, or otherwise make decisions that significantly impact users.

The Google Business Model

The lecture frames this critically — through the lens of surveillance capitalism.

The Direct Definition

To extract as much personal data from as many people in the world at the lowest possible price and to resell that data to as many companies as possible at the highest possible price. Jonathan Taplin, Move Fast and Break Things

How it works

Google itself doesn't pirate music; it doesn't have to. It's selling the traffic — and, just as significant, the data about the traffic. Elizabeth Kolbert, The New Yorker

Surveillance Capitalism (Shoshana Zuboff)

  • Google created the first insanely lucrative markets to trade in human futures — what we now call online targeted advertising — based on predictions of which ads users would click.
  • Between 2000 (when this logic emerged) and 2004 (Google's IPO), revenues increased by 3,590% — Zuboff calls this the "surveillance dividend."
  • This reset the bar for investors, driving startups, app developers, and established companies to shift their business models toward surveillance capitalism.
  • It spread first to Facebook, then through the tech sector, then throughout the rest of the economy — insurance, retail, finance, education, healthcare, real estate, entertainment, and every product called "smart" or "personalized."
Surveillance capitalism is "a new economic order that claims human experience as a free source of raw material." We are the resource to be mined. Jacob Silverman (NYT), on Zuboff

Why doesn't the government stop it?

The government has built a surveillance apparatus by purchasing commercially available data rather than conducting traditional surveillance — neatly sidestepping warrant requirements. As one government consultant put it: "the largest information-gathering enterprise ever conceived by man. And it wasn't built by the government."

Network Architectures at a Glance

  • Centralized: one hub → fragile
  • Decentralized: multiple hubs (AT&T model) → still fragile per region
  • Distributed: every node interconnected → redundant, survives node failures → what the internet is built on
